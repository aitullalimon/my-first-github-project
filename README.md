
# My First GitHub Project

My first GitHub repository for learning Git,
GitHub, and Python programming.

- Python 3

## Installation
Clone the repository:

```bash
git clone https://github.com/aitullalimon/my-first-github-project.git
```

## Run the Program
```bash
cd my-first-github-project
python3 hello.py
```

```text
Hello, GitHub!
This is my first GitHub project.
```
